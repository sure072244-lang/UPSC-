# PRECISION V8.7 — Password + Performance Repair

## Scope
Continuation from V8.6.1-CONTINUED. This release is strictly additive/reparative: the existing V8.4/V8.6.1 data, OMR flow, schedule, AI, study tracking, navigation, 50-slot engine, and 46-paper schedule are preserved.

## Security gate change
- Removed the active WebAuthn/passkey startup dependency.
- Added a first-run portal password gate.
- Passwords are never stored in plaintext.
- Browser Web Crypto PBKDF2-SHA-256 derives a 256-bit salted hash (120,000 iterations by default).
- Lock/unlock and change-password controls remain available from Admin/Settings.
- The password is never sent to Mistral, Vercel, or any API endpoint.

## Mock schedule behavior
- 46 imported schedule papers remain linked to the existing 50 mock slots.
- D-Day date and 09:30–11:30 IST test window remain enforced.
- Two-minute pre-start countdown is schedule-aware.
- At the scheduled date/time, the active scheduled mock can auto-arm/start from the saved schedule state.
- Outside the scheduled window, the mock remains frozen.
- Existing manual launch, dry-run/QA, schedule editing, OMR, result, and official-key flows remain available.

## Performance repairs
- Search index remains lazy and is not part of initial hydration.
- Shell-first rendering is preserved.
- Startup cache namespace bumped to V8.7.
- Service-worker query/version bumped to avoid stale V8.6.1 assets.
- Existing content-visibility and focused-tab scrolling behavior retained.
