# PRECISION V8.3 FINAL — Boot/Runtime Recovery Release

Preserves the V8.2 feature/data set and adds runtime reliability fixes.

## Fixes
- Boot splash is fail-safe and cannot remain indefinitely.
- Legacy local-storage persistence call is promise-safe.
- Critical scripts are loaded in deterministic order after the DOM shell.
- Service-worker cache migration clears prior PRECISION caches once per session and uses a new cache namespace.
- Service-worker offline fallback no longer serves index.html for JavaScript/data/image requests.
- Startup recovery screen appears instead of a blank/dead main area when a module fails.
- Mistral Small 4 model defaults to `mistral-small-2603`, with a non-web Chat Completions fallback.
- Existing V7/V8.2 data, study tracker, mock engine, OMR, answer-key flows, AI history and UI features are retained.

## Deployment
For Vercel, set `MISTRAL_API_KEY` and optionally `MISTRAL_MODEL=mistral-small-2603` as a server-side environment variable.
For full cloud sync and cross-portal key persistence, use the included Cloudflare Worker + D1 architecture; Vercel static/serverless hosting alone does not provide durable D1 storage.
