# V8.2-FINAL Release Notes

## Scope
V8.2 is the reliability/performance consolidation of the StudyTracker-style personal UPSC portal layer.

## Key fixes
1. **Blank-page / dead-button root cause:** the legacy render path could invoke a large blocking data load before the V8 shell was active. V8 now sets an explicit active marker before boot, and the legacy blocking branch is skipped while V8 owns startup.
2. **Study time contamination:** the study analytics ledger is computed from active study sessions only. Page visits and dashboard browsing do not count as study minutes.
3. **Background recovery:** active study time uses wall-clock timestamps so time survives app/tab backgrounding; visual redraw can be throttled by the browser and catches up on resume.
4. **PYQ data:** the local master remains 1,300 records covering 2014–2026, with question text/options metadata available in the packaged master for the locally complete records.
5. **OMR pipeline:** extracted answers move into Review and the reviewed state can be promoted into Key Vault Draft, finalized against the exact paper code, optionally supplemented by an independently imported Official Answer Key, then evaluated.
6. **Cross-portal key bridge:** `/api/key` + D1 provides a bearer-style share-code path for transferring a final 100-answer key between portals when D1 is configured.
7. **D-Day scheduling:** each test receives a date and a 09:30–11:30 IST window. Outside the date/window the test is frozen; Dry-run is explicitly separate from live access control.
8. **AI:** Mistral Small 4 family via `mistral-small-latest`, streamed through a backend proxy. The browser never needs the provider secret.
9. **Device lock:** WebAuthn platform authenticator flow is retained and error messages are more specific. Passkeys remain bound to the exact origin.
10. **Performance:** large search index remains lazy; service-worker cache excludes it from the initial cache; the V8 shell renders before large data hydration.
