# PRECISION UPSC GS-I — V8.7.5 Stability Release

## Purpose
Continuation repair from the V8.7.4/V8.6.1 workflow. Existing application/data files are preserved; this release adds a stability/UX patch rather than replacing the portal architecture.

## Fixed / strengthened
- Fixed desktop layout so the left sidebar is static and non-scrolling; the central content area is the primary vertical scroll surface.
- Kept mobile navigation compact and fixed at the bottom without a second page scroll surface.
- Preserved focus-tab behavior: non-home pages can hide the sidebar and retain the internal Back control/history stack.
- Added keyboard Back guard (Alt+Left / Ctrl/Cmd+[) where the internal Back control is available.
- Hardened first-run WebAuthn/passkey registration with multiple compatible authenticator-selection variants.
- Added deterministic local-password fallback when the browser/device credential manager returns an unknown/unsupported error.
- Passkey credentials remain local; no credential is sent to Mistral/Vercel/API.
- Preserved 2-minute pre-start countdown + 120-minute scheduled mock window.
- Scheduled mock panel remains frozen outside its imported schedule window.
- Schedule edits continue to update the engine mapping and date/day/month together.
- Added a lightweight live schedule cockpit/status surface without a heavy WebGL renderer.
- Added a cache namespace bump to V8.7.5 and updated service-worker precache entries.
- Preserved the existing 242-feature registry; the existing 50 V8.7.4 operational features remain intact.
- Preserved 1,300 PYQs, 46 schedule papers, 11 workbook sheets, and 60 Mains trend rows.
