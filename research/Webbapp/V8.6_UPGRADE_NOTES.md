# PRECISION V8.6 Integrated Upgrade

## Scope
Additive upgrade of the repaired V8.4 personal UPSC CSE Prelims 2027 GS-I portal.

## New data layers
- `data/schedule_2027_v1.json` — normalized 46-paper schedule.
- `data/schedule/UPSC_Prelims_2027_46_Test_Calendar_Final-2.xlsx` — selected source workbook.
- `data/mains_gs_trend_2013_2026.json` — 60 supplied Mains topic rows from the four user-provided screenshots.
- `data/sources/mains_screenshots/` — screenshot provenance copies.
- `data/feature_registry_v86.csv` — original features plus 20 AI + 10 schedule additions (192 registered features total).
- `data/system_manifest_v86.json` — system/data linkage manifest.

## AI integration
- English-first structured UPSC response policy.
- Factual vs descriptive/analytical intent routing.
- Prelims keywords, Mains answer frame, current-affairs linkage.
- A-to-Z portal context snapshot covering study ledger, activity, tests, results, OMR/evaluation, answer keys, Mains trend, schedule, training notes, AI memory and local PYQ retrieval.
- Separate normal/web Mistral conversation IDs for follow-up continuity.
- Built-in `web_search` only on new Mistral conversations; follow-up appends omit `tools` to avoid `extra_forbidden` errors.
- Persistent browser AI memory/training notes.
- Safe AI admin command layer with allow-listed actions.

## Schedule integration
- Final-2 workbook selected because its `CA_Sync` source-hierarchy table is populated; Final-3 has that subsection incomplete.
- 46 schedule papers linked into the existing first 46 mock slots without deleting the remaining 4 engine slots.
- Editable schedule overrides, CSV/JSON export, schedule-to-engine sync, CA-window and conflict audit actions.

## Official answer key
- Dedicated Official Answer Key tab added while retaining the existing OMR/evaluation/key-vault workflow.
- Key is stored separately and bound to the selected paper code.

## Navigation and UI
- Sticky sidebar + independently scrolling main content.
- Focus mode hides sidebar for the active tab.
- Persistent back-stack returns to the actual prior view.
- Liquid-glass cards, 3D/ambient visual layers, color-coded subject pills, content-visibility/performance tuning.

## Security
The startup gate requires WebAuthn platform passkey creation on first use and verification on subsequent starts. This protects the local device/browser session. It is not equivalent to server-side multi-user authentication.

## Explicit limitations
- Mains screenshots do not provide separate Ancient/Medieval/Modern Mains rows; no artificial split is created.
- Prelims labels are used as supplied by the portal corpus; subjects not separately tagged are displayed as `— / not separately tagged`, not as zero questions.
- Vercel `/api/sync` remains configuration-dependent; without durable storage such as D1/DB, backend process-memory sync is not a durable cross-instance database. V8.6 browser memory remains localStorage-based.
- Container Chromium could not provide a reliable live browser pass; package/static/smoke/local-HTTP checks are used instead.
