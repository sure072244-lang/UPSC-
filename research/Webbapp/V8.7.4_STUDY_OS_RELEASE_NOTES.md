# PRECISION UPSC GS-I — V8.7.4 STUDY OS

## Continuation point
This release continues from the V8.7.3/V8.6.1 work directory and preserves the existing application/data archive. No original package file was deleted.

## Critical fixes
- Replaced the duplicate/fragile first-run WebAuthn path that could surface `Unknown error occurred while talking to the credential manager`.
- Added a deterministic Secure Gate V4: device passkey first, explicit local-password fallback when the browser/device credential manager cannot complete registration.
- Removed the automatic `registerDeviceOnlyPasskey()` startup call that could trigger the failing credential-manager path before the main portal boot.
- Fixed a pre-existing syntax error in `passkey-hybrid-v3.js`.
- Bumped service-worker/application cache namespaces to V8.7.4 to prevent stale deployments.

## UI / performance
- Retired the 3D Intelligence navigation surface and human 3D navigator from the active UI.
- Added **Study Command • Tracker Intelligence** as the lighter replacement.
- Sidebar is vertically scrollable on desktop; main content is independently scrollable.
- Mobile keeps the sidebar as a horizontally scrollable bottom navigation strip.
- Added smoother scrolling, overscroll containment, scrollbar handling and a performance mode.
- Preserved the focus-tab mode: individual pages can hide the sidebar and expose a Back control.

## Schedule → Mock automation
- Preserved the supplied 46-paper schedule and all 11 imported workbook sheets.
- Schedule edits remain local and reversible.
- Schedule editor now exposes the core schedule fields including date, type, level, group, subject/topic, CA window/focus, paper code, direct/indirect questions, CA target, round, stage focus, timing, gap and portal note.
- Added automatic schedule-to-engine synchronization.
- Added automatic **2-minute pre-start countdown + 120-minute test window** using the scheduled Timing field.
- Outside the scheduled window, an automatically scheduled engine run is frozen/submission-ready; manual starts remain date/window gated.
- Edited schedule dates/times are used by the automation layer.

## AI integration
- Existing Mistral Small 4 backend remains `/api/ai` with `mistral-small-2603`.
- Portal context continues to include PYQ corpus, study ledger, mock/test engine, OMR/evaluation, answer-key state, schedule, workbook sheets, Mains trend data, AI memory and feature registry.
- English-by-default response policy remains active.
- Factual vs descriptive response routing and Prelims/Mains formatting remain active.
- Added 50 new Study OS features and registered them as IDs 193–242.
- Added local AI/feature controls for readiness, adherence, weak-flow navigation, result tracking, OMR/key monitoring, AI memory, feedback, backup integrity, sync and performance.
